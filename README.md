# Valentines

### A Valentine's Day themed game I made for my partner at the time

It utilizes a software rendering technique essentially ripped from ID Software's early *Wolfenstein* games.
It started as just following a tutorial made by the Youtuber 3DSage on creating a *Wolfenstein* inspired renderer.

On my own, I added functional enemies, the combat system, levels, doors, and more.
I hand-coded the animations for the game and recorded some of the sounds myself -- not very well or with much effort.
I learned a lot about managing many files interacting with one another here, and also got a lot of hands on experience
turning assets like sound and visuals into something *usable* in a game. 

I have consistently had the goal of creating miniature games without the assistence of a game engine.
Not that I don't believe in game engines, I very much do, but I really believe that to learn something you should
have some understanding of each layer of the process, even if just to acknowledge the system as a whole.
